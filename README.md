# Roast Your Own Agent

One line roasting the AI agent my own team built — Muse Spark ("priadi"), an agentic coding assistant.

> My agent delegated my task to a subagent, which delegated it back, and both billed me for the meeting.

The sting is specific, not generic: this agent delegates work to subagents as a matter of habit, so the joke is the loop closing back on itself — the subagent hands the task straight back, and both of them still charge for the meeting. Delegation that goes nowhere, billed twice.

`main.py` writes the line deterministically to `/output/entry.txt` (102 chars, no trailing newline). Bounty: https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54
